# Mekanism: Этилен + Gas-Burning Generator — полный расчёт

## Конфиг сервера

Значения из `/config/Mekanism/`:

| Параметр | Значение | Файл |
|----------|----------|------|
| PRC энергия/тик | 5 J | machine-usage.toml |
| Crusher энергия/тик | 50 J | machine-usage.toml |
| Electric Pump энергия/оп | 100 J | machine-usage.toml |
| Separator энергия/тик | 400 J (= 2 × HydrogenEnergyDensity) | расчётное |
| Max upgrade multiplier | 10x | general.toml |
| HydrogenEnergyDensity | 200 J/mB | general.toml |
| FE conversion rate | 2.5 J = 1 FE | general.toml |
| GBG бак | 18,000 mB | generators.toml |
| Ethylene burn ticks | 40 тиков/mB | generators.toml |
| Ethylene density multiplier | 40 | generators.toml |
| Bio generation | 350 J/t | generators.toml |

## Формулы улучшений

**Обычные машины** (PRC, Crusher, Pump):

```
Скорость:   BaseTicks × 10^(-speed/8)
Энергия/t:  Base × 10^((2×speed - energy) / 8)
```

**Электролитический сепаратор** (особая механика):

```
Скорость:   2^speed операций/тик  (×2 за каждый upgrade, до 256×)
Энергия/t:  Base × 10^(2×speed / 8)   ← energy upgrades НЕ работают
```

> Каждый speed upgrade удваивает скорость сепаратора (не ×1.33 как у обычных машин). Energy upgrades не влияют на потребление — это design decision для баланса.

## PRC (Pressurized Reaction Chamber)

Рецепт: 1 Bio Fuel + 10 mB воды + 100 mB H₂ → 100 mB этилена + Substrate

| Параметр | Без улучшений | 8 speed + 8 energy |
|----------|:-------------:|:-------------------:|
| Время операции | 100 тиков (5 сек) | 10 тиков (0.5 сек) |
| Выход этилена/оп | 100 mB | 100 mB |
| **Скорость этилена** | **1 mB/t** | **10 mB/t** |
| Потребление H₂ | 1 mB/t | 10 mB/t |
| Потребление воды | 0.1 mB/t | 1 mB/t |
| Потребление Bio Fuel | 1 шт / 100 тиков | 1 шт / 10 тиков |
| Энергия | 5 J/t (2 FE/t) | 50 J/t (20 FE/t) |

## Electrolytic Separator (Электролитический сепаратор)

Рецепт: 1 mB воды → 1 mB H₂ + 1 mB O₂

| Параметр | Без улучшений | 8 speed |
|----------|:-------------:|:-------:|
| Операций/тик | 1 | 256 |
| **Выход H₂** | **1 mB/t** | **256 mB/t** |
| Выход O₂ | 1 mB/t | 256 mB/t |
| Потребление воды | 1 mB/t | 256 mB/t |
| Энергия | 400 J/t (160 FE/t) | 40,000 J/t (16,000 FE/t) |
| **Эффективность** | **400 J/mB** (160 FE/mB) | **156 J/mB** (62.5 FE/mB) |

> С ростом speed upgrades эффективность **улучшается**: скорость ×256, энергия ×100 → каждый mB H₂ обходится в 2.56 раз дешевле.

## Electric Pump (Электрическая помпа)

Качает 1,000 mB (1 ведро) воды за операцию из бесконечного источника (2×2 пул).

| Параметр | Без улучшений | 8 speed + 8 energy |
|----------|:-------------:|:-------------------:|
| Тиков на операцию | 19 | 1 |
| **Скорость** | **52.6 mB/t** | **1,000 mB/t** |
| Энергия/оп | 100 J (40 FE) | 1,000 J (400 FE) |
| **Энергия/тик** | **5.3 J/t (2.1 FE/t)** | **1,000 J/t (400 FE/t)** |

> Для этиленовой цепочки хватает **1 помпы без улучшений** — максимальная потребность ~22 mB/t << базовых 52.6 mB/t. Улучшения на помпу — лишняя трата ресурсов.

## Gas-Burning Generator

| Параметр | Значение |
|----------|----------|
| Энергия за 1 mB этилена | 200 + 2 × 350 × 40 = **28,200 J/mB (11,280 FE/mB)** |
| Макс. скорость сжигания | 256 / 40 = **6.4 mB/t** |
| **Макс. выход энергии** | **180,480 J/t (72,192 FE/t)** |

Формула burn rate: `ceil(256 × stored / capacity) / ethyleneBurnTicks`

> GBG сжигает на максимуме (6.4 mB/t) только при полном баке. Если бак пустеет — скорость падает пропорционально.

## Оптимальные соотношения

### С максимальными улучшениями (PRC: 8 speed + 8 energy)

```
1 PRC = 10 mB/t этилена
1 GBG = 6.4 mB/t потребление

10 / 6.4 ≈ 1.56 генератора на 1 PRC
```

| Схема | Этилен | Потребление GBG | Излишек | Выход энергии |
|-------|--------|-----------------|---------|---------------|
| **1 PRC : 1 GBG** | 10 mB/t | 6.4 mB/t | +3.6 mB/t | ~72k FE/t |
| **2 PRC : 3 GBG** ★ | 20 mB/t | 19.2 mB/t | +0.8 mB/t | ~216k FE/t |
| **3 PRC : 5 GBG** | 30 mB/t | 32 mB/t | −2 mB/t | нестабильно |

**Рекомендация: 2 PRC : 3 GBG**

### Без улучшений

```
1 PRC = 1 mB/t этилена
1 GBG = до 6.4 mB/t потребление (с полным баком)

При 2 mB/t подаче бак GBG стабилизируется на ~31% (5,625 mB).
```

| Схема | Этилен | GBG | Выход энергии |
|-------|--------|-----|---------------|
| **1 PRC : 1 GBG** | 1 mB/t | бак ~10% | ~11k FE/t |
| **2 PRC : 1 GBG** ★ | 2 mB/t | бак ~31% | ~22k FE/t |
| **4 PRC : 1 GBG** | 4 mB/t | бак ~56% | ~45k FE/t |

**Рекомендация: 2–4 PRC : 1 GBG** (1 GBG справляется с 6.4 mB/t)

## Полный энергобаланс

### С максимальными улучшениями — 2 PRC : 3 GBG

| Компонент | Кол-во | Улучшения | Энергия/тик | Примечание |
|-----------|:------:|-----------|:-----------:|------------|
| PRC | 2 | 8s + 8e | −100 J/t (40 FE/t) | 20 mB/t этилена |
| Separator | 1 | 8 speed | −3,125 J/t (1,250 FE/t) | 20 mB/t H₂, duty cycle 7.8% |
| Pump | 1 | без | −5 J/t (2 FE/t) | 22 mB/t воды |
| **Расход** | | | **−3,230 J/t (1,292 FE/t)** | |
| GBG | 3 | — | +541,440 J/t (216,576 FE/t) | 19.2 mB/t × 28,200 J |
| **Чистая энергия** | | | **+538,210 J/t (~215,284 FE/t)** | overhead 0.6% |

> Сепаратор (8 speed) производит 256 mB/t H₂, но нужно только 20 mB/t. Машина работает ~7.8% времени (duty cycle), средний расход энергии: 40,000 × 20/256 = 3,125 J/t.

### Без улучшений — 2 PRC : 1 GBG

| Компонент | Кол-во | Улучшения | Энергия/тик | Примечание |
|-----------|:------:|-----------|:-----------:|------------|
| PRC | 2 | без | −10 J/t (4 FE/t) | 2 mB/t этилена |
| Separator | 2 | без | −800 J/t (320 FE/t) | 2 mB/t H₂ |
| Pump | 1 | без | −5 J/t (2 FE/t) | 2.2 mB/t воды |
| **Расход** | | | **−815 J/t (326 FE/t)** | |
| GBG | 1 | — | +56,400 J/t (22,560 FE/t) | 2 mB/t × 28,200 J |
| **Чистая энергия** | | | **+55,585 J/t (~22,234 FE/t)** | overhead 1.4% |

### Сравнение

| | Без улучшений | С максимальными |
|---|:---:|:---:|
| Машин всего | 6 (2 PRC + 2 Sep + 1 Pump + 1 GBG) | 7 (2 PRC + 1 Sep + 1 Pump + 3 GBG) |
| Чистая энергия | **~22k FE/t** | **~215k FE/t** |
| Overhead | 1.4% | 0.6% |
| Главный расход | Separator (98%) | Separator (97%) |

> В обоих случаях **сепаратор — главный потребитель энергии** цепочки (97–98%). PRC и помпа почти бесплатны.

## Цепочка производства

```
  Органика (дыни, семена)
         │
         ▼
    [ Crusher ] ──→ Bio Fuel
                        │
                        ▼
  [ Pump ] ─→ Вода ─→ [ Electrolytic Separator ] ─→ H₂ ──┐
               │              │                            │
               │              └─→ O₂ (побочный продукт)    │
               │                                           │
               └──────→ [ PRC ] ←── Bio Fuel + Вода + H₂ ─┘
                            │
                            ▼
                     Ethylene ──→ [ Gas-Burning Generator ] ──→ Энергия
                            │
                            └──→ Substrate (побочный продукт)
```

**Подача ресурсов:**
- **Bio Fuel**: Crusher (дыни — лучший выход: 1 ломтик → 4 bio fuel). ~2 Crusher на 1 PRC
- **Вода**: Electric Pump из бесконечного источника (2×2 пул воды). 1 помпы хватает на всю цепочку
- **H₂**: Electrolytic Separator (вода → H₂ + O₂). 1 базовый сепаратор на 1 базовый PRC, или 1 сепаратор (8 speed) на всю цепочку
- **O₂**: побочный продукт, можно сбросить через Gas Vent или использовать в других рецептах
