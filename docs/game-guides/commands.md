# KIBERmine — Полезные команды

> Справочник команд для сервера KIBERmine (Mohist 1.20.1).

## Пользовательские команды

### Авторизация (AuthMe)

| Команда | Описание |
|---------|----------|
| `/register <пароль> <пароль>` | Регистрация на сервере (при первом входе) |
| `/login <пароль>` | Вход в аккаунт |
| `/changepassword <старый> <новый>` | Смена пароля |

## Полезные советы

- **Локальный чат** работает в радиусе 100 блоков. Используй `!` перед сообщением для глобального чата
- **Клеймы чанков** защищают территорию от грифа — заклеймь свою базу через карту (M) или `/ftbchunks claim`
- **Случайная телепортация** `/rtp` имеет кулдаун 10 минут — используй для поиска нового места
- **Три дома** доступно по умолчанию — используй осмысленные названия (`/sethome base`, `/sethome farm`)
- **Смайлики в чате**: `:)` → ☺, `:D` → ☻, `<3` → ❤, `:ok:` → 🖒
- **Голосовой чат** работает через мод Simple Voice Chat — клавиша **V** для настроек
