# Simple Voice Chat — Руководство

## Для игроков

### Установка

1. Скачать мод **Simple Voice Chat** для Forge 1.20.1:
   https://modrinth.com/plugin/simple-voice-chat/versions?g=1.20.1&l=forge
2. Поместить `.jar` файл в папку `mods/` вашего клиента
3. Перезапустить Minecraft

### Управление (клавиши по умолчанию)

| Клавиша | Действие |
|---------|----------|
| **V** | Открыть настройки голосового чата |
| **Caps Lock** | Говорить (push-to-talk) |
| **H** | Отключить/включить звук от других |
| **M** | Отключить/включить свой микрофон |
| **G** | Открыть меню групп |

> Клавиши можно изменить в Настройки → Управление → Voice Chat

### Как начать говорить

1. После входа на сервер в правом нижнем углу появится иконка микрофона
2. Нажми **V** — откроется меню голосового чата
3. Выбери устройства ввода/вывода и настрой громкость
4. Зажми **Caps Lock** чтобы говорить (по умолчанию push-to-talk)
5. Игроки рядом (до 48 блоков) услышат тебя

### Режимы активации

В настройках (клавиша **V**) можно выбрать:

- **Push-to-Talk** — говоришь пока зажата клавиша (по умолчанию)
- **Voice Activation** — автоматически включается при разговоре

### Группы

- Нажми **G** чтобы открыть меню групп
- Создай группу — друзья смогут присоединиться
- В группе слышно друг друга на любом расстоянии и даже из разных измерений
- Группа может быть открытой (все видят) или закрытой (по паролю)

### Шёпот

- Зажми **Shift + Caps Lock** чтобы шептать
- Шёпот слышен на расстоянии до 24 блоков (вместо обычных 48)

### Если не работает

| Проблема | Решение |
|----------|---------|
| Нет иконки микрофона | Убедись, что мод установлен на клиенте |
| Иконка с крестиком | Проверь настройки микрофона в системе |
| Не слышу других | Нажми **H** (возможно, звук отключён) |
| Другие не слышат меня | Нажми **M** (возможно, микрофон отключён) |
| "Connection refused" | Проверь что UDP порт 24454 не блокируется файрволом/VPN |

## Для администраторов

### Установленные моды

| Мод | Файл | Назначение |
|-----|------|------------|
| Simple Voice Chat | `voicechat-forge-1.20.1-2.6.6.jar` | Основной голосовой чат |
| Broadcast | `simplevoicechat_broadcast-mc1.20.1-1.0.1.jar` | Вещание на весь сервер |
| Simple Radio | `simpleradio` (встроен) | Радиосистема с антеннами и рациями |

### Конфигурация сервера

Файл: `/opt/minecraft/config/voicechat/voicechat-server.properties`

| Параметр | Значение | Описание |
|----------|----------|----------|
| `port` | `24454` | UDP порт голосового чата |
| `bind_address` | *(пусто)* | Привязка к IP (пусто = server-ip) |
| `voice_host` | `217.114.7.232:24454` | Внешний адрес для подключения клиентов |
| `max_voice_distance` | `48.0` | Дистанция обычного голоса (блоки) |
| `whisper_distance` | `24.0` | Дистанция шёпота (блоки) |
| `codec` | `VOIP` | Кодек Opus (VOIP/AUDIO/RESTRICTED_LOWDELAY) |
| `mtu_size` | `1024` | Макс. размер аудио-пакетов (байт) |
| `enable_groups` | `true` | Групповые чаты разрешены |
| `allow_recording` | `true` | Запись голоса разрешена |
| `force_voice_chat` | `false` | Не кикать без мода |

### Сетевая архитектура

```
Игрок → UDP:24454 → VPS (DNAT) → WireGuard → Proxmox → MC Server:24454
```

- UDP порт 24454 проброшен через VPS DNAT (`/etc/ufw/before.rules`)
- `voice_host` указывает на внешний IP VPS — клиенты подключаются туда

### Права (LuckPerms)

Следующие права установлены для группы `default` (все игроки):

| Разрешение | Описание |
|------------|----------|
| `voicechat.listen` | Слушать голосовой чат |
| `voicechat.speak` | Говорить в голосовой чат |
| `voicechat.groups` | Использовать группы |
| `voicechat.groups.create` | Создавать группы |

Команды управления правами:
```bash
# Дать право группе
lp group default permission set voicechat.listen true

# Забрать право у группы
lp group default permission set voicechat.listen false

# Проверить права игрока
lp user <ник> permission check voicechat.listen
```

Дополнительные права для администраторов:

| Разрешение | Описание |
|------------|----------|
| `voicechat.admin` | Полный доступ к настройкам |
| `voicechat.groups.permanent` | Создание постоянных групп |

### Broadcast (вещание на весь сервер)

Конфиг: `/opt/minecraft/config/simplevoicechat_broadcast.toml`

| Параметр | Значение | Описание |
|----------|----------|----------|
| `broadcast_group_name` | `broadcast` | Имя группы вещания |
| `permission_level` | `2` | Уровень доступа (2 = оператор) |

Использование:
1. Быть оператором (или иметь permission level 2+)
2. Создать группу с именем `broadcast`
3. Всё сказанное в группе транслируется всем игрокам на сервере

### Simple Radio (радиосистема)

Конфиг: `/opt/minecraft/config/simpleradio-server.toml`

Добавляет блоки и предметы для радиосвязи:

| Предмет/блок | Назначение |
|-------------|------------|
| Walkie-Talkie | Рация — общение на частотах |
| Transceiver | Приёмопередатчик |
| Transmitter | Передатчик |
| Receiver | Приёмник |
| Antenna | Антенна — увеличивает дальность |
| Radio | Радио — воспроизводит сигнал |
| Speaker | Динамик — транслирует звук |
| Microphone | Микрофон — захватывает звук |

Игроки настраивают частоту на рации и общаются на выбранном канале.

### Troubleshooting

**Проверить что голосовой чат работает:**
```bash
# В логах при подключении игрока должно быть:
grep "successfully connected to voice chat" /opt/minecraft/logs/latest.log

# Проверить что UDP порт слушается:
ss -ulnp | grep 24454
```

**Если игроки не могут подключиться к голосовому чату:**
1. Проверить `voice_host` в конфиге — должен быть внешний IP
2. Проверить проброс UDP порта на VPS: `iptables -t nat -L PREROUTING -n | grep 24454`
3. Проверить UFW route: `ufw status | grep 24454`
4. Тест UDP: `nc -zuv 217.114.7.232 24454` с внешней машины

**Изменить дистанцию голоса:**
```properties
# В voicechat-server.properties
max_voice_distance=48.0    # обычный голос (блоки)
whisper_distance=24.0      # шёпот (блоки)
```
После изменения — перезапустить сервер.
